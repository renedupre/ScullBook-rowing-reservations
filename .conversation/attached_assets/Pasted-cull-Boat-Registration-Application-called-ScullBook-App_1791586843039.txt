Application should start with a splash page a logo with a picture of an 9 person scull on a lake and the title ScullBook.  
Application will have an Admin Screen for Boat Configuration and data setup as well as viewing upcoming reservations.  
Rower Screen will allow the registered rower to reserve or cancel a spot on a boat.
 
Login and register buttons are in the top right corner of initial splash page. 
Allow user to select Login button and enter their email and password in a pop-up dialog box.  
If user selects register button, they will be greeted with a welcome message for new rowers and be prompted to supply their email as their user id and a password.  Enforce 10 digit complex password rules with one special character and at least one Upper and one lower case letter, and one number.
Also collect their first name and last name.
Password should be entered twice to ensure it is entered correctly.
User hits submit button to create their account which is stored in a database.
Password need not be encrypted for this application.  

The user list table needs to have an identifier for the application administrator which will sign in with the ID “admin” and not follow e-mail format rules.  Initial default password will be “Happy$1234”.   Admin will have a function to change their password which is also stored in the database. 

Admin screen - Boat Configuration 
Screen to set up boats which has a boat name, boat type, number of rower seats.
Boat types are “Single Scull” which is a one person boat, “Double Scull” which is a two person boat, “Quadruple Scull” which is a four person boat, “Octuple Scull” which holds 9. 

The Octuple Scull’s first person’s position is at the stern of the boat and it called the “Coxswain” and faces forward.  All other rowers face backward.  The person next to the Cox is the “Stoke seat”.

Set available dates and assign boats that are available to register for on that date.

Admin screen - Reservations

Admin screen should have a logout button. 


Rower’s Reservation screen.
